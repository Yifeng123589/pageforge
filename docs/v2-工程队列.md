## 一、筛选原则

### 准入（满足任一条）
1. **让小白能自己做出好看的页面**——对齐、样式、模板、主题、素材
2. **降低「分享出去」的门槛**——在线版、导出、分享卡
3. **让操作不别扭**——仅在「做出页面」的流程里**已经出现痛感**时才做
4. **成本极低且直接加分**——复用 v1 零依赖模块、capabilities/适配层类改动

### 拒绝（及理由）
| 理由 | 典型被拒项 |
|---|---|
| **对标专业工具，不是我们的用户** | 混合模式、色标渐变编辑器、HSL/RGB/HEX 三模式、自定义旋转原点、快捷键自定义、命令面板、面板浮动拖拽 |
| **没有用户的场景** | 多人协作、评论批注、版本分支、权限管理、云同步（还破坏「本地优先零锁定」） |
| **过早优化** | 虚拟化、Web Worker、差分快照、500+ 元素限制、will-change 调优、PWA |
| **破坏信任模型** | 用户写 JS 渲染函数、导入包执行代码（供应链风险） |
| **与已定产品定义冲突** | 响应式导出（media queries）——canvas 页**放弃响应式是模式定义** |
| **等有真实用户再说** | ARIA/WCAG 全套、屏幕阅读器、高对比度、对比度检查器 |

> **修正**：原「不做」清单曾把**触控板双指手势**以「与响应式冲突」为由拒绝——**理由错了**（这是输入支持，不是响应式）。正确处置见 B 批说明：**它随 `Ctrl+滚轮`/`滚轮` 自动获得，不需要单独实现**。

## 二、现状基线（2026-09-14，已逐项核实）

**v2 已有**：加块（**3 个**）· 拖拽/吸附/八点缩放/旋转 · 多选框选 · 双击改字 · 右键菜单（复制/置顶/置底/删除）· 样式面板（**仅**容器背景/圆角/内边距 + 叶子颜色/字号/行高）· 图片（URL/base64）· 6 种滚动动效 · 撤销重做（200 帧）· 页面增删切换 · 缩放/适配 · 导出单文件 HTML · 混排导出

**已核实的「阻断性缺陷」**（不是"别扭"，是"不能用"）：
| 缺陷 | 核实方式 | 后果 |
|---|---|---|
| **无 IME 处理** | `textedit.js` 中 `composition` 出现 **0** 次 | **中文输入会炸**（组字过程被当作提交）→ 中文用户打不了字 |
| **无画布平移** | `interact.js` 中 pan/middle/space 相关 **0** 处 | 放大后看不到画布边缘，**只能缩回去** |
| **无滚轮缩放** | v2 各模块 `wheel` **0** 处（滚动靠 viewport 原生） | 无法以光标为中心缩放 |
| **编辑内 Ctrl+Z 退出编辑** | `main.js:154` 全局 `Ctrl+Z → undo()`，**不判断是否在编辑态** | 编辑器内改字时按 Ctrl+Z，直接退出整个编辑会话 |

**v2 的 AI 缺口**（`canvasAdapter.capabilities`）：
```
chat: true   placeBlock: true   freeHTML: false   style: true
replace: true   gen: false   color: false   diag: false
```
→ 配色/诊断/初稿在 v2 被 UI 自动隐藏。**小白最需要的「帮我配个色」「看看我哪里丑」恰好是关的**。

## 三、★可复用资产（最大的成本红利）

`blocks.js` / `templates.js` / `themes.js` / `assets.js` / `block-html.js` **对 GrapesJS 零引用**（已逐个核实）：

| v1 模块 | 体积 | 依赖 | v2 用法 |
|---|---|---|---|
| `blocks.js` | 70KB | 零 | 块定义模式无关（**D1 迁移的基础**） |
| `templates.js` | 9.9KB | 零 | **A1 起步模板** |
| `themes.js` | 4.7KB | 零 | **A2 主题换肤** |
| `assets.js` | 16.6KB | 零 | **A7 素材库** |
| `block-html.js` | 1.6KB | 零 | 块 HTML 构建 |
| `color-panel.js` | 6.6KB | 2 行 | 小改即可复用 |

**读法**：凡标「复用」的项，**成本是"接 UI + 适配"，不是"重写"**。

**依赖提示**：**A2（主题系统）是 A8b（AI 配色）的前置**——配色的产物是"调色板"，而 canvas 页要能"一键应用调色板"，必须先有主题机制；否则只能逐个元素改色。

## 五、B 批｜让操作不别扭

> 理由：**PageForge 当前零用户**，"收集 N 个用户反馈"这类条件永远不满足；用 dogfooding 替代，客观且立刻可执行。

| **视口** | 滚轮垂直滚动 · **Ctrl+滚轮以光标为中心缩放** · Ctrl++/− · Ctrl+0 适配 / Ctrl+1 实际大小 · 惯性平移 |
| **图层** | 图层面板（z 序列表 / 拖拽排序 / 显示隐藏 / **锁定切换（原缺失项 1，数据模型已有 `locked` 无 UI）** / **重命名（图层面板的前提）** / 选中联动） |

| 6 | **README「在线试用」入口** | 顶部放链接 + 开屏截图 |
| 7 | **隐私说明** | 清楚写出：页面数据只存在浏览器本地，AI 请求发往用户自己填的服务商 |
