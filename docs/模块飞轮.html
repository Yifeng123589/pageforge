PageForge 模块飞轮 · 完整循环

主循环 = AI 按目录拼块（日常，零人工） · 结晶环 = 缺口变新块（低频，人只做验收） · 补给环 = 拆站按同一模板供弹药
目录命中（省 token 路径 ~30 tok） fallback 裸生成（贵 ~400+ tok，但被日志捕获） 结晶环（缺口 → 新块，人工仅验收） 拆站补给（方向一，同一模板产出）
北极星指标：库覆盖率
命中率 = 目录命中 ÷（命中 + fallback）。越高 = 拼装越省、风格越稳。目标：常见需求 90%+ 命中。
单次成本对比
命中 ~30 tok vs fallback 400+ tok；输入侧还能把 4000 字符页面全文换成块目录+骨架，再省一截。
人工只出现在结晶环
日常拼装零人工；人只做两件事：审缺口值不值得入库、验收新块。AI 起草，人签字——生成一次，永久复用。
